# OutBreak-Graficas-Cmputacionales-en-Web
Servicios Web La aplicación debe consumir un servicio web para transferir información entre la aplicación y un servidor web. La teconología para el servicio web es a  elección del alumno (PHP, JAVA, .NET) Almacenamiento La aplicación debe contar con almacenamiento local y remoto con el uso de LocalStorage/Cookies y MySQL o SQLServer
